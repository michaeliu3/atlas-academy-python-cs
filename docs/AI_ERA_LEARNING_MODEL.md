# AI-era learning model

Atlas Academy treats AI as an implementation collaborator whose work requires
human specification and review.

~~~text
understand → model → constrain → delegate → inspect → test → explain → decide
~~~

The learner should be able to state:

- the system boundary and user outcome;
- the representation and invariant at stake;
- the architecture and dependency direction;
- the evidence a proposed change would need;
- the smallest bounded task suitable for an agent;
- the tests/measurements that distinguish a correct patch from a plausible one;
- the remaining unknowns after the work passes.

The course rewards this judgment through code-reading labs, incident analysis,
architecture maps, agent briefs, patch reviews, confidence-aware questions, and
capstone defense. It does not reward accepting generated code because it looks
plausible.
