## Implementation record

M26's **External-track selection check** now requires exactly three inspectable
facts: (1) recent project activity and a contribution route, (2) a real
documented issue/request or the Atlas-local fallback, and (3) the
maintainer/community authority boundary. It retains the privacy-safe local
reproducer/review as the default when those facts are absent. This is an
original, bounded Atlas adaptation; it does not create public-submission,
merge, community-contact, external-data, review, or release evidence.

The remaining release-time evidence gap is operational rather than authoring:
a qualified, voluntary M26 TA conversation must actually exercise the
changed-premise defense and review a dossier before anyone describes the oral
flow as learner-delivered. That future interaction must stay non-grading,
privacy-conscious, and distinct from institutional peer, staff, or maintainer
feedback.
