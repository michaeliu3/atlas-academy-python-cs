# M24 candidate-only structural preflight

## Candidate boundary

This document records a structural candidate preflight for M24's current
workbook, typed six-session packet, source ledger, runtime-evidence
observatory, bounded reference model, and module-scoped companion. It does not
change M24's `legacy-baseline` contract state, `legacy-open` learner
availability, or unrecorded release state.

The candidate does not bind an exact source commit to a successful CI run, a
human source or teaching review, a private deployment record, a security
clearance, a release, a publication decision, an oral-defense result, a live
chat session, a Notion write, or learner mastery. Those remain separate
evidence questions; the release criterion stays explicitly open.

## Structural scope

The candidate requires M24's six connected runtime-evidence sessions,
measurement and attribution reasoning, code-reading/debugging/design tasks,
confidence-aware diagnostic, spaced retrieval, runtime dossier, accessible
diagram text, supportive oral-defense route, and bounded teaching model. Its
source-ledger scope is limited to the canonical M24 source map and source-audit
addendum.

## Later review questions

A future human review must still inspect interpreter/runtime claims, source
authority and licensing, real keyboard/screen-reader experience,
psychological safety, and exact source-commit CI/deployment provenance before
any lifecycle or publication claim changes.
