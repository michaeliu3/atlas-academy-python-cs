# M23 candidate-only structural preflight

## Candidate boundary

This document records a structural candidate preflight for M23's current
workbook, typed six-session packet, source ledger, language/interpreter
studio, bounded reference model, and module-scoped companion. It does not
change M23's `legacy-baseline` contract state, `legacy-open` learner
availability, or unrecorded release state.

The candidate does not bind an exact source commit to a successful CI run, a
human source or teaching review, a private deployment record, a security
clearance, a release, a publication decision, an oral-defense result, a live
chat session, a Notion write, or learner mastery. Those remain separate
evidence questions; the release criterion stays explicitly open.

## Structural scope

The candidate requires M23's six connected language/evaluation sessions,
syntax-to-authority reasoning, code-reading/debugging/design tasks,
confidence-aware diagnostic, spaced retrieval, query-language dossier,
accessible diagram text, supportive oral-defense route, and bounded teaching
model. Its source-ledger scope is limited to the canonical M23 source map and
source-audit addendum.

## Later review questions

A future human review must still inspect language and capability claims, source
authority and licensing, real keyboard/screen-reader experience,
psychological safety, and exact source-commit CI/deployment provenance before
any lifecycle or publication claim changes.
