# M21 candidate-only structural preflight

## Candidate boundary

This document records a structural candidate preflight for M21's current
workbook, typed six-session packet, source ledger, async/distributed studio,
bounded reference model, and module-scoped companion. It does not change
M21's `legacy-baseline` contract state, `legacy-open` learner availability, or
unrecorded release state.

The candidate does not bind an exact source commit to a successful CI run, a
human source or teaching review, a private deployment record, a security
clearance, a release, a publication decision, an oral-defense result, a live
chat session, a Notion write, or learner mastery. Those remain separate
evidence questions; the release criterion stays explicitly open.

## Structural scope

The candidate requires M21's six connected async/distributed sessions,
ownership and partial-failure reasoning, code-reading/debugging/design tasks,
confidence-aware diagnostic, spaced retrieval, async evidence dossier,
accessible diagram text, supportive oral-defense route, and bounded teaching
model. Its source-ledger scope is limited to the canonical M21 source map and
source-audit addendum.

## Later review questions

A future human review must still inspect distributed-systems claims, source
authority and licensing, real keyboard/screen-reader experience,
psychological safety, and exact source-commit CI/deployment provenance before
any lifecycle or publication claim changes.
