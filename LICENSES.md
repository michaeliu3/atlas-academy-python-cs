# Source and license policy

## Repository status

Atlas Academy is a private course project. No public license is granted for
the original curriculum, visual material, code, tests, or Atlas artifacts until
the repository owner explicitly selects one. Do not copy material from this
repository into a public project without the owner’s permission.

## Original material

The course explanations, original diagrams, teaching grammars, local fixtures,
visual studios, assessment prompts, tests, and Atlas examples are authored for
this course. They should remain attributable to Atlas Academy and its
contributors.

## Third-party material

- Prefer links and original paraphrase over copied prose, diagrams, exercises,
  slides, or solutions.
- Use official Python documentation, PEPs, standards, university course pages,
  and open-source source code only for the claims each source actually
  supports.
- Preserve notices and follow upstream terms for any copied code, example, or
  asset.
- Python documentation is available under the Python Software Foundation
  License Version 2; documentation code examples also carry a Zero-Clause BSD
  permission. Verify current terms before reuse.
- University course material may be copyrighted even when publicly readable.
  Use it for sequencing and reference, not for reproducing assignments or
  solutions.

Each module source map records its links, claim boundaries, and relevant
licensing guidance.
