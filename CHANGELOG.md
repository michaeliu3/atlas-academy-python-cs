# Changelog

All meaningful changes are recorded here. Version labels describe verified
course/repository milestones, not claims of learner mastery or a published
GitHub Release. A GitHub Release is claimed only after its Release page is
actually published.

  React Server Components, ESLint-Next, and Vite patch versions after reviewing
  the private dependency alerts. Resolution remains subject to GitHub's
  post-merge advisory rescan; no claim is made that every transitive advisory is

  documented the AI-era learning philosophy, privacy boundary, content

  not treat configuration alone as evidence of a GitHub CI run or Release.

  artifacts, ignored local Python caches, and documented the explicit
  `github`/`origin` deployment policy.
- Preparing Module 23, Programming Languages, Interpreters & Bounded
  Evaluation, for the visual portal and local teaching-model release.
